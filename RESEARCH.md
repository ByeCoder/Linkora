# Product research and implementation choices

[English](RESEARCH.md) · [فارسی](RESEARCH_FA.md)

Public first-party descriptions were reviewed on **2026-11-14**. This review did not involve signing in to, messaging, or testing every private feature of the referenced bots.

| Reference | Publicly described capability | Linkora implementation |
| --- | --- | --- |
| SearcheeBot / TGStat | Keyword and category-based channel discovery | Public Waybien search, category filters, curated topics and this bot's own popular searches |
| LivegramBot | Telegram feedback-bot builder | Numbered support tickets, copied media, operator replies from a group or private chat, ticket closure |
| ControllerBot | Channel posting tools and statistics | Preview/confirmation for broadcasts and analytics for Linkora's own recorded events |
| Telegram Bot API | Deep links, multilingual command menus, defined button styles and eligible custom-emoji icons | Referrals/campaign attribution, eight-language UI, presentation settings and a plain-button fallback |

Points, streaks, saved-search notifications, optional leaderboard participation and membership targets are Linkora's own product choices for discovery and retention. They are not presented as verified features shared by all the referenced bots.
